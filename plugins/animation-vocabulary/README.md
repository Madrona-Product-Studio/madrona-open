# animation-vocabulary — name the motion effect you're picturing

A reverse-lookup glossary for web motion. You describe the effect in plain
words ("the bouncy thing when a popover opens", "the iOS rubber-band scroll",
"text that wipes in with a gradient edge") and it returns the exact term —
*Pop in*, *Rubber-banding*, *Gradient wipe* — plus close neighbors so you can
tell near-misses apart.

## Why that matters

You can't prompt for what you can't name. An AI (or a designer) given "make it
feel bouncier" guesses; given "spring entrance, slight overshoot,
origin-aware from the trigger" it builds the right thing the first time. The
glossary covers entrances/exits, scroll effects, hover/press states, layout
transitions, physics feels, and the fuzzy adjectives in between.

Use it in the other direction too: when reviewing motion, it gives you the
precise word for what's wrong.

Pairs with `motion-options` (explore directions) and `review-animations`
(enforce the craft bar).
